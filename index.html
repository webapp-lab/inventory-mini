      Mode Lokal (hanya perangkat ini)

      Data hanya tersimpan di HP ini. Hubungkan Firebase agar semua pegawai bisa berbagi data.

      Cara Hubungkan Firebase (Gratis)

      1

      Buka console.firebase.google.com

      2

      Klik "Add project" → beri nama → klik Continue sampai selesai

      3

      Pilih Build → Realtime Database → Create Database

      4

      Pilih "Start in test mode" → Enable

      5

      Salin URL database, contoh: https://nama-rtdb.firebaseio.com

      Pastikan URL tidak diakhiri dengan garis miring (/). Bagikan file HTML ini ke semua pegawai — cukup isi URL sekali di tiap HP.
